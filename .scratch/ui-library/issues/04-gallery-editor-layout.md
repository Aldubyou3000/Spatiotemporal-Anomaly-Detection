## Question

What layout and interaction model lets the user find a real component, inspect its variants/states and edit its appearance locally? Create a small disposable prototype after supported controls and the local entry are settled, then get the user's reaction. Cover component navigation, editing controls, responsive preview, light/dark preview and reset. Do not add a publishing or export/apply workflow. The prototype must remain separate from live operations and must not be mistaken for completed implementation.
